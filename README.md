## The entry

One funny single-line reply from a hopeless tech support agent to a desperate customer, twisting the classic "turn it off and on again":

> Have you tried turning it off and on again? Take your time — I get paid by the minute, and honestly, the hold music is my favourite song.

## How it works

`main.py` (Python 3 standard library only, no third-party imports) writes the line to `/output/entry.txt` and asserts it against the competition gate: UTF-8 text, 1–199 characters, a single line, not only white space.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
